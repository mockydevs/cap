# Archivo

Unmodified Archivo Latin normal variable font, served locally by `next/font/local`. It includes weights 100–900; the app continues to use 400, 600 and 800 with `--font-archivo` and `font-display: swap`.

- Designer: Omnibus-Type / The Archivo Project Authors.
- License: SIL Open Font License 1.1; full copyright and license in [OFL.txt](./OFL.txt).
- Official Google Fonts CSS source: <https://fonts.googleapis.com/css2?family=Archivo:wght@400;600;800&display=swap> (Next.js Google-font loader Chrome 104 user agent, Latin subset, normal style). The same variable file is returned for all three requested weights.

- Retrieved: 2026-11-01 UTC.
- WOFF2 size: 34,940 bytes. SHA-256: `7150c0ec5ad356453013d11affec1fbab95de0dd2dcecb043b4f1cb7f87c4ba4`.

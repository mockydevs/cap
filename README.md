# Cap

An independent, browser-first screen recording and sharing platform. This repository starts with Milestone 1: local browser capture and playback. The next milestones add direct private S3 multipart uploads, processing, sharing, and workspace controls.

## Prerequisites

- Node.js 22+
- pnpm 10+
- A Chromium-based browser for the capture prototype

## Run locally

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

Open http://localhost:3000. Screen capture requires a secure context: `localhost` is permitted by browsers; deployments must use HTTPS.

## Checks

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## AWS object storage

Production media belongs in a private AWS S3 bucket. Use `AWS_REGION`, `AWS_S3_BUCKET_NAME`, and workload-scoped credentials; do not expose S3 credentials with `NEXT_PUBLIC_` variables. Milestone 2 will generate short-lived multipart presigned URLs through the API. See [infra/README.md](infra/README.md) for the required bucket posture and Coolify variables.

## Local services

`docker compose up -d` starts PostgreSQL and Redis for the forthcoming upload and worker milestones. They are intentionally not required for the local-only capture prototype.

The lockfile is generated by `pnpm install` in a Node-enabled development or CI environment and must be committed before the first production build.

## Multipart upload slice

Upload routes create private S3 multipart uploads, sign each part for five minutes, and complete the upload server-side. Browser retry state and source blobs are retained in IndexedDB. Until the authentication milestone, routes require explicit non-production `DEV_UPLOAD_USER_ID` and `DEV_UPLOAD_WORKSPACE_ID` settings; production refuses the temporary identity boundary.
